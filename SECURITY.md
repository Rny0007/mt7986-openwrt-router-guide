# Security Policy

## Supported Versions

This documentation project tracks recent official OpenWrt stable releases targeting the MediaTek Filogic architecture.

| Component | Status |
| :--- | :--- |
| OpenWrt 25.12.x | Actively Maintained & Verified |
| Older releases | Community Reference Only |

## Reporting Security Issues

If you discover a security concern, an accidental credential exposure, or a vulnerability in any configuration example:

1. **Do not create a public issue** with sensitive data, tokens, passwords, or router configuration dumps.
2. Report the vulnerability privately via GitHub Security Advisories or directly to the repository maintainer.
3. Include clear steps to reproduce the issue without including real network secrets or private keys.

## Public Safety Notice

- Never paste private SSH keys, Wi-Fi passwords, ISP PPPoE credentials, or router full-chip flash dumps into public issues or discussion forums.
- Always sanitize network traces and configuration outputs using generic placeholders before sharing.
