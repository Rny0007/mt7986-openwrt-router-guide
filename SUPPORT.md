# Support & Community Help

Thank you for consulting the MT7986 OpenWrt Router Guide.

## Where to Get Help

- **Documentation**: Browse the detailed guides in the [`docs/`](docs/) directory.
- **Frequently Asked Questions**: Review [`docs/faq.md`](docs/faq.md) and [`docs/troubleshooting.md`](docs/troubleshooting.md).
- **GitHub Discussions**: For general questions, community setups, and hardware inquiries, visit the repository Discussions tab.
- **GitHub Issues**: If you detect factual errors, broken links, or have verified compatibility data for a new device revision, please open an Issue.

## Star the Project
